# Security

Claude Switch reads Claude Code's local session files and starts the Claude Code CLI and the Claude desktop
app as the account you choose. It keeps separate sign-ins apart. A fault that mixes accounts up, passes one
account's login to another, or sends anything off the computer is a security fault.

## Reporting

Please report it privately: on the repository's **Security** tab choose **Report a vulnerability**. Do not
open a public issue for it.

Say what you did, what happened, and the version. You will get an answer within a week.

## Supported versions

Only the latest release gets fixes.
