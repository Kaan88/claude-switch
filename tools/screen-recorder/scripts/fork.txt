# `/fork` (Claude Switch item 80): one turn, then `/fork`, then a second turn. `live` writes what
# the CLI's live record (`sessions/<pid>.json`) names and copies every transcript at that moment:
# before the fork, right after it, and after the next turn. The check says whether the record moves
# to a new session, whether that session's transcript is written at once or only with the next
# message, and whether the transcript the fork leaves names it in a `continued-in` record, which
# Chat follows. Two model requests. `/fork` also starts a background session holding a copy of
# the conversation, which this script does not stop: end it afterwards (`claude agents`).
#: args --permission-mode default
#: seconds 80
start
send Reply with just the word: alpha
sleep 800
send \r
sleep 1500
gone esc to interrupt 60000
quiet 1500 30000
snap idle
live before
send /fork
sleep 800
send \r
sleep 3000
quiet 2000 30000
snap forked
live forked
send Reply with just the word: bravo
sleep 800
send \r
sleep 1500
gone esc to interrupt 60000
quiet 1500 30000
snap after
live after
